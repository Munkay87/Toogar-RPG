# Toogar RPG

Toogar RPG is a Python role-playing game developed as a learning project while building practical experience with Python and game development.


## Project Status

Version 1 - Working Release


## Version 1 Features

- Tkinter graphical user interface
- Player character system
- Enemy system
- Turn-based combat
- Loot system
- Character progression
- Packaged and tested as a Windows application using PyInstaller


## Technologies Used

- Python
- Tkinter
- PyInstaller
- Git
- GitHub


## How to Run

### From Source

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open the project folder.
4. Run:

```bash
python main.py
```

### Windows Version

A packaged Windows version of Toogar RPG is available through GitHub Releases section.


## Future Development

Toogar RPG will continue to be developed beyond Version 1, with new features, improvements, and expanded gameplay added as development progresses.
